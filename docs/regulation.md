## 日程・連絡

- 競技時間: **2026-10-31(土) 10:00〜18:00 JST**（8時間）
- 全体アナウンス: Discord
- 競技中の質問: **ポータル**（回答は原則全チームに公開）
- 競技前後の質問: Discord

## サーバー

- 各チームの AWS アカウントで、主催者が競技開始後に指定する AMI から EC2 を起動する。起動方法は当日マニュアルに書かれる
- **マニュアルどおりに作った EC2 以外の利用は禁止事項にあたる**可能性がある
- AWS アカウントに元からあるリソースや設定が原因の問題は、主催者のサポート対象外

## 変更してはいけないもの

- アクセス先の URI（サーバー側で生成する ID などは、文字種を変えなければ変更してよい）
- レスポンス（HTML の DOM、JSON オブジェクトなど）の構造。表示に影響しない空白の増減は可
- JavaScript / CSS ファイルの内容
- 画像・動画などメディアファイルの内容

## 変更してよいもの（一切禁止しない）

- ソフトウェアの入れ替え、設定変更、アプリのコード変更・入れ替え
- DB スキーマ変更、インデックスの作成・削除
- キャッシュ追加、ジョブキューによる遅延書き込み
- 他言語での再実装（提供予定言語: Go / Perl / PHP / Python / Ruby / Rust / Node.js）

## 守るべき条件

- 主催者のメンテナンスコマンドとの互換性を保つ
- **サーバー再起動後もすべてのアプリが正常に動く**（systemd の enable 忘れに注意）
- **ベンチマーク中に書き込まれたデータが再起動後も取得できる**（オンメモリだけに置いて永続化しない、は不可）

## 採点・追試・失格

- 採点条件を満たしたチームの中で、ベンチマーカーのスコアを比べる。条件の詳細は当日マニュアル
- 競技終了後、主催者が **再起動を含む追試** を行う。複数台の再起動順序は保証されない
- 次のどれかに当てはまると失格:
  - 追試でベンチマークが正常に完了しない
  - 競技中のスコアに近い結果が再現されない
  - 結果に捏造があると判断される
  - 禁止事項への違反

→ **終了前に全台再起動 → ベンチ → スコアが再現することを確認する時間を必ず取る**。順序を変えた再起動でも起動すること（DB 待ちのリトライなど）。

## 禁止事項

- 競技終了まで、問題内容やベンチマーカーの計測方法などを公開・共有すること（推察させる発言も含む）
- 他チームとの結託。競技時間中に、チーム外の人と問題についてやりとりすること（SNS 含む）
- ベンチマーク中に、認められたサーバー以外の外部リソースを使うこと（**他インスタンスへの処理委譲など**）
- ベンチマーカーへのログイン試行など、割り当てられていないサーバーへの接続や不正アクセスの試み
- 他チームや競技の妨害

## 明示的に許可されていること

- モニタリング・テスト・開発に、手元の PC や外部サーバーを使うこと
- 開発で AI を使ったコードの分析・生成
