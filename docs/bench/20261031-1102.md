## 結論（優先度順）

1. **DB の CPU が詰まっていて、主な原因はインデックス不足による全件スキャン**。`realmojis(image_id)` と `friendships(user_high_id)` へのインデックス追加が最も効きそう。安全で即効性もある
2. europe と america はクエリ1本ごとに RTT 100ms がかかり、ユーザーが投稿期間内に処理を終えられず脱落している。DB の負荷を下げたあとに、クエリ数の削減やリージョン側でのキャッシュを検討する
3. ロック待ち（`LOCK TABLE users`、`posting_windows FOR UPDATE`）も目立つ。DB の CPU が空いたあとに改めて確認する
